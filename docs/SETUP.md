# Track 7: Stranded Assets

Our analysis is in `track7_stranded_assets.ipynb`.

## Setup

Install Python 3.11, then open a terminal in this folder and run:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m notebook
```

On macOS or Linux, use `python3.11` instead of `py -3.11` and `.venv/bin/python` instead of `.\.venv\Scripts\python.exe`.

## Run the notebook

1. Keep the supplied files in the `data/` folder, with their original names.
2. Open `track7_stranded_assets.ipynb` in Jupyter.
3. Select **Kernel > Restart Kernel and Run All Cells**.

Each run reads the supplied raw data and takes a few minutes. Results are displayed in the notebook; figures and table files used by the report are saved in `figures/`.
